# 无障碍要求

目标为常见 WCAG 2.2 AA 对应体验；本包列出项目检查项，不构成第三方合规认证。自动检查只能覆盖部分问题，最终需要手动键盘与读屏抽查。

- 一个页面一个主 h1，导航、main、表单和表格使用语义元素；图表带文本摘要与同值表格。
- 页面顶部提供 Skip to content；路由变化更新 document.title 并合理移动焦点至页面标题。
- 全流程键盘可操作；无 hover 独有动作；顺序符合视觉阅读顺序。
- 弹窗拥有可访问标题/描述，焦点进入、陷阱、Esc、安全关闭及返回；训练输入错误弹窗关闭后保留字段上下文。
- 所有表单有持久 label，placeholder 不代替 label；错误使用 aria-invalid 和 aria-describedby。
- 触摸目标以 44px 为项目标准；正文 4.5:1，大字 3:1，关键边界与状态 3:1。装饰分隔线不承担控件边界语义。
- 200% 缩放可用；在 320 CSS px 的回流检查中正文与表单不需页面级横向滚动；已使用 360px 常规设备检查仍不足以代替该项。
- 成功保存用 polite live region；严重错误用 alert；计时只在开始/结束等事件播报，不能每秒报秒。
- 不依赖颜色、方向或图标辨识唯一含义。完成组、选中计划等同时具备文字或程序语义。
- prefers-reduced-motion 禁用非必要动画；系统高对比模式下焦点可见。
- 检查系统字体回退、长英文标题换行和软键盘打开后的字段可达。

手动路径：用 Tab/Shift+Tab/Enter/Space/Escape 完成开始训练、两组输入、结束确认、打开详情、导出数据；使用桌面系统读屏工具抽查导航、统计与一组输入。报告注明实际工具和版本，不宣称未检查的读屏环境通过。
