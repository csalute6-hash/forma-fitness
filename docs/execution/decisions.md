# 已设定默认决策

这些决策使工程包可直接执行；用户后续变更时使用 ADR 并更新关联文档。

| ID | 决策 | 原因 | 影响 |
|---|---|---|---|
| D001 | 本地单用户 MVP，无登录 | 不引入后端账号即可实现真实记录闭环 | 无云同步，不承诺跨设备 |
| D002 | 英文 UI、中文工程文档 | 对齐界面要求与阅读便利 | 所有用户可见提示英文 |
| D003 | kg canonical，单位只在边界换算 | 避免重复舍入导致历史漂移 | UI 单位切换不改历史 |
| D004 | completedLocalDate + timeZone | 跨时区回顾保持完成日稳定 | 时间分组需要显式字段 |
| D005 | 全量替换导入，单根提交 | 降低合并与部分导入丢数据风险 | 用户先预览确认 |
| D006 | 计划快照、完成训练只读 | 计划修改不污染历史 | 历史只能删除，不能编辑 |
| D007 | 白色、绿色强调、无外部字体 | 满足简约大气并减少网络依赖 | 依赖系统字体、无照片要求 |
| D008 | 清空个人数据保留内置库和模板 | 保持空状态可继续开始训练 | 文案明确清除范围 |
| D009 | 可靠单写策略，多标签冲突阻断 | localStorage 不具备读改写事务 | 需锁或单写模式 |
| D010 | 身高不采集，仅保留长度偏好 | P0 核心为训练与体重记录 | 不显示空洞身高面板 |

待实现者记录的决策：具体依赖版本、测试运行器、跨标签降级实现、图表库（若使用）、浏览器验证版本。不要将这些空白写成已完成选型。
