# 产品需求 PRD

## 产品与目标
FORMA 是桌面优先的个人力量训练记录工具。用户可以从计划快速开始训练，逐组记录实际表现，结束后查看可靠的历史和趋势。核心价值是低干扰记录与数据可信。界面为英文，视觉简洁、留白充足、白色占主导。

## 用户与情境
- 规律训练者：使用固定计划，每次训练记录重量与次数，希望刷新后继续。
- 初次使用者：选择预置计划，查看动作说明，用最少操作开始第一场训练。
- 回顾者：查看最近训练、每周频率和个人纪录，导出数据留存。

桌面 1440px 作为主设计基准，手机 390px 作为完整功能验收设备。支持 360px 起的窄屏。所有功能通过鼠标、触屏、键盘使用。P0 不包含离线资源缓存或安装为 PWA 的承诺；应用加载完成后，记录操作不依赖远程 API。

## 成功判据（产品目标，非上线后的已测结果）
- 从 Dashboard 到开始预置训练的标准路径不超过三次主要点击。
- 一组训练可在同一行完成重量、次数、完成状态的记录，不需要页面跳转。
- 刷新与浏览器重开后恢复同一未完成训练，包含已保存输入与开始时间。
- 任意看板数值能够追溯到完成训练或体重记录，不出现无来源的卡路里数值。
- 导出后再导入到空存储，领域数据一致，派生数值可重新计算。

## P0 范围
Dashboard、训练记录器与历史、计划管理、动作库、训练与体重趋势、单位与数据管理、响应式和无障碍。逐条合同见 [需求目录](catalog.md)。P0 全部通过才可将 MVP 标记为完成。

## 明确排除
账户与密码、云端同步、多用户协作、教练后台、营养与饮食、自动能量消耗、心率与可穿戴、付费订阅、社区、通知推送、第三方视频、生成式 AI。不得加入不可用的占位入口。计划日期仅标注训练日标签，不自动生成日历或提醒。

## 主旅程
1. 打开 Dashboard，看到本周目标和推荐计划。
2. 浏览 Plans → 查看计划 → Start workout；无活跃计划则显式选择计划。
3. 记录各组实际重量与次数；可新增组、移除组、更换动作。
4. 随时离开页面，返回时继续当前训练；只有一场活跃训练。
5. Finish workout → 确认摘要 → 保存历史；看板与趋势立即更新。
6. 在 Progress 记录体重；在 Settings 导出或导入自己的数据。

## 默认与边界
首次运行加载合成 demo 数据，并在 Settings 显示 “Demo data is loaded on this device.”；清除数据后进入真实空状态，不在下次刷新偷偷重建 demo。周一为周起点，周目标默认 3 次，范围 1–14。默认 kg/cm。休息计时默认 90 秒，可选择 30 / 60 / 90 / 120 / 180 秒。正常记录过程中不请求网络授权。

## 变更管理
新增 P0 或改变存储语义必须同步需求、状态、测试、验收矩阵。P1 想法记录到 backlog，不得挤占 P0 闭环。生产联网扩展是另一个里程碑，不能用本地 MVP 的通过结论代替生产验收。
