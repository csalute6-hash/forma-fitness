# 产品与 UI 实现规则

1. 页面有明确主要操作；所有看起来可点击的元素都必须有真实作用。不可用功能不展示假入口。
2. 所有 UI 为英文；数据库 ID 不作为标题；长英文合理换行，禁止靠截断隐藏关键重量、次数或错误。
3. 白色为主、扁平化；使用共享 token，不在不同页面临时创造新圆角、按钮色或阴影。
4. 数据读取与错误状态真实存在；本地读取很快时不加人为延迟，异步真实存在时才显示加载。
5. 写入中防重复，失败保留输入；成功提示只在存储完成之后出现。
6. 跳转前处理未提交草稿；取消确认必须无副作用。删除、替换已完成组与导入替换均明确说明损失范围。
7. 响应式改变布局而非隐藏功能。手机上计划编辑、数据导入与导出同样可用。
8. 数值字段始终可辨识单位；体重与训练负重范围不同，不能共用错误文案。
9. 图表有单位、范围与替代数据表；图形漂亮不能代替统计准确。
10. 无数据时提供下一步操作；过滤无结果和初次没有记录是不同状态。

每个交互完成后验证：鼠标路径、键盘路径、手机触摸布局、刷新后的实际数据。视觉验收不得只检查 Dashboard，记录器、编辑器、空状态和错误状态同样重要。
