# 安全与隐私规则

## 本地 MVP
- 只收集产品需要的训练和体重数据，不要求生日、地址、疾病史、姓名或联系方式。
- Settings 明确说明本机存储、浏览器清理风险、导出备份方式。localStorage 不是加密保险箱；不宣称端到端加密或云端备份。
- 训练名、计划名、备注、导入文本全部作为纯文本；禁止 innerHTML / eval / Function 等执行用户输入。
- 导入拒绝 `__proto__`、`prototype`、`constructor` 等危险键；对象按 schema 构建，不把不可信对象直接深合并进配置。
- 文件大小限制在读入和 schema 校验两层考虑；不执行导入文件中的 URL 或命令；只接受 JSON。
- 禁止第三方分析、广告、外部视频、远程字体或图片。若未来确需，必须更新产品范围和隐私说明。
- 错误日志不打印体重与整份备份；调试数据清理后再交付。
- 清除和导入替换必须确认；恢复不能未经同意覆盖损坏数据。备份下载失败应可见。

## 必须检查的攻击样例
计划名 `<img src=x onerror=alert(1)>` 应显示为普通文本；导入超大数组应拒绝；非法数字与日期应拒绝；嵌套危险键应拒绝。用户输入很长时界面不溢出，存储拒绝仍可恢复。

## 联网边界
只有 [生产扩展](../architecture/production-extension.md) 实现且复验后才可宣称支持账户或云同步。生产环境令牌不放前端源码或导出 JSON。这里不提供特定地区法律合规结论。
