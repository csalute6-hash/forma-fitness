# 验证策略与确定性

## 分层
1. 领域单元：schema、范围、单位、日历窗口、容量、纪录、状态迁移、模板快照、不变量。
2. 存储适配：写失败、坏 JSON、版本未知、revision 冲突、单 key 原子完成、导入取消/失败、清空与首次初始化区分。
3. 组件：数字草稿、表单错误、弹窗焦点、选择器回填、完成按钮 gating、计时状态。
4. E2E：用户路径、刷新/重开、深链接、多标签、导入导出、空状态。
5. 手动与视觉：响应式、长内容、键盘、读屏抽查、对比、真实图表、错误反馈。

## 确定性输入
所有自动测试使用 [fixture 说明](../../fixtures/README.md) 的固定时钟与时区。领域层注入 clock，测试 ID 可注入确定性工厂；生产路径不使用测试时钟。每个测试重置隔离存储，不依赖执行顺序或上一个测试的数据。浏览器多标签测试共享同一上下文，普通测试使用隔离上下文。

## 命令与证据
脚本合同见 [技术约定](../architecture/technical-contract.md)。每次执行记录环境、依赖锁、代码版本、命令、退出码和摘要。E2E 失败保留 trace / 截图；截图不含真实用户数据。自动 a11y 工具不得代替键盘和读屏人工检查。

## 边界最小集
0 / 500kg、1 / 100 reps、空值、负值、小数 reps、NaN、极大值、lb 上限；周日到周一、跨午夜、非 UTC 时区和夏令时环境；只有自重的零容量训练；一组完成其余未完成；取消删除；导入重复 ID/悬空引用；quota；并发写入；长标题；系统时钟倒退；200 条上限；窗口宽度变化与焦点恢复。

## 浏览器
主验证：安装环境中的 Chromium 桌面与手机模拟；兼容复验：当前环境可用的 Firefox、WebKit。报告实际版本。至少 Chromium + 一个第二引擎主链通过才能满足兼容门槛；缺第二引擎则标 BLOCKED，而非用“应兼容”代替。移动模拟不等同真实 iOS 设备实测，应在报告中区分。
